# VEDA Frontend

## Prerequisites
- Node.js LTS
- npm

## Initial setup
From this directory, create the Next.js app with TypeScript and Tailwind if it is not already scaffolded:
`npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"`

Then install dependencies:
`npm install`

Run the development server:
`npm run dev`

Open http://localhost:3000.
